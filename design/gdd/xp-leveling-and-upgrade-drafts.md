# XP, Leveling, and Upgrade Drafts

> **Status**: Approved
> **Author**: Sean + Codex
> **Last Updated**: 2026-05-14
> **Implements Pillar**: Power Fantasy First

## Overview

`XP, Leveling, and Upgrade Drafts` defines run XP, Color Mote pickup flow, level thresholds, normal level-up drafts, Page Event reward drafts, slot legality, and overflow behavior. It owns temporary run progression and draft generation rules. It does not own weapon behavior, passive item behavior, Page Event objective logic, evolution replacement behavior, or HUD layout.

Design source consulted: `PAGEBOUND_CODEX_GDD_v1_5.md`; `design/gdd/mvp-weapon-candidate-pool.md`; `design/gdd/mvp-item-candidate-pool.md`; `design/gdd/page-events-and-objectives.md`; `design/gdd/passive-items-and-drafts.md`; `design/gdd/evolution-system.md`; first polished exemplar grilling session, 2026-05-14.

## Player Fantasy

Every level-up should feel like a normal fast roguelite draft: three useful choices, one pick, back to action. New gear can appear from level-ups, but the player is not forced along fixed weapon-only levels and does not need a pity system.

## Detailed Design

### Core Rules

1. Run XP resets every run.
2. Enemies, Page Events, destructibles, and boss/finale drops may produce XP pickups called Color Motes.
3. Filling the XP threshold increments run level and opens a normal 3-choice draft.
4. Every draft generated by this system shows exactly 3 choices.
5. Normal level-up drafts use a per-card roll: `90%` upgrade, `10%` new gear.
6. New gear rolls split `50%` new weapon and `50%` new passive item.
7. Upgrade rolls split `50%` owned weapon upgrade and `50%` owned item upgrade.
8. A new weapon is legal only when the player has an open weapon slot and an unowned weapon exists.
9. A new passive item is legal only when the player has an open item slot and an unowned item exists.
10. A weapon upgrade is legal only for an owned weapon below level 10.
11. An item upgrade is legal only for an owned item below level 5.
12. New gear enters at level 1.
13. Owned weapon and item upgrade cards grant exactly +1 level.
14. If a rolled type is illegal, redirect to the other legal type in the same family where possible.
15. If new gear is rolled but neither new weapon nor new item is legal, redirect to upgrades.
16. If upgrades are rolled but neither weapon nor item upgrades are legal, redirect to new gear.
17. If no normal weapon/item card is legal, drafts switch to overflow rewards.
18. Overflow rewards are small repeatable global stat crumbs. Current prototype crumb: `+5%` to a named global stat.
19. There are no fixed weapon-only draft levels.
20. There is no pity system.
21. There are no elite/chest reward drafts in current scope.
22. Boss/finale reward drafts are not part of the first polished exemplar package.
23. Pagecraft modifiers, rare utility rewards, temporary super attacks, heals, magnets, event evolutions, and pet-synergy cards are not part of this draft canon.
24. Luck can tune rarity or future presentation later, but it does not change the `90/10` category split or `50/50` weapon/item split.

### Page Event Reward Drafts

Page Event rewards use the same normal 3-choice draft rules with one addition:

- If the player has an open gear slot and at least one unowned legal gear entry exists, at least one card must be new gear.

The forced new-gear card still uses the `50%` new weapon and `50%` new item split, with redirect to the other legal gear type when the rolled side is unavailable. Remaining cards are normal flex cards: upgrade or gear according to the same `90/10` roll and legality redirects.

Page Events do not have stronger pools, evolution rewards, Pagecraft modifiers, chest rewards, or temporary super attacks in the current approved draft model.

### First Polished Exemplar Pool

The first polished exemplar intentionally uses a tiny pool:

| Type | Entry | Notes |
|---|---|---|
| Starting weapon | `Waxlight Comet` | Owned at run start, level 1. |
| Passive item | `Candle Spark` | Only item in first package. |

Because the player starts with `Waxlight Comet`, a new weapon roll has no legal unowned weapon in the first package and redirects to `Candle Spark` if it is still legal. If `Candle Spark` appears before the first Page Event reward, that is acceptable. If it has not appeared, the first successful Page Event reward guarantee points at `Candle Spark`.

The tiny pool can temporarily underfill distinct 3-card choices during implementation. Prototype may allow repeated simple upgrade targets only after all distinct legal normal cards have already been represented. Full content pool should avoid duplicate target/action cards within the same draft.

### States and Transitions

| State | Description | Valid Transitions |
|---|---|---|
| `CollectingXP` | Player collects Color Motes toward next level. | `LevelReady`, `RunEnded` |
| `LevelReady` | Threshold reached; draft can be generated. | `DraftOpen` |
| `DraftOpen` | Three choices are presented. | `DraftSelected`, `DraftCancelledByRunEnd` |
| `DraftSelected` | Choice is applied to weapon/item/overflow state. | `CollectingXP` |
| `DraftCancelledByRunEnd` | Death/victory interrupts draft. | `RunEnded` |
| `RunEnded` | Temporary XP/progression stops. | none |

| System | Direction | Contract |
|---|---|---|
| Resource Data Schemas | Upstream | Provides weapon/item IDs, levels, display metadata, and unlock gates. |
| Weapons and Auto-Attacks | Downstream | Adds new weapons and upgrades owned weapons. |
| Passive Items and Drafts | Downstream | Adds new passives and upgrades owned passives. |

## Formulas

`xp_after_pickup = current_xp + pickup_value * xp_gain_multiplier`

`level_ready = xp_after_pickup >= xp_threshold_for_next_level`

`draft_choice_count = 3`

`normal_card_roll = upgrade if rng < 0.90 else new_gear`

`new_gear_type_roll = new_weapon if rng < 0.50 else new_item`

`upgrade_type_roll = weapon_upgrade if rng < 0.50 else item_upgrade`

`overflow_draft_allowed = no_legal_new_weapon and no_legal_new_item and no_legal_weapon_upgrade and no_legal_item_upgrade`

Invalid states:

- A draft generated by this system has not exactly 3 choices.
- Draft offers a new weapon with no open weapon slot or no unowned legal weapon.
- Draft offers a new passive item with no open item slot or no unowned legal item.
- Draft offers an upgrade for a maxed weapon or item.
- An owned weapon or item upgrade grants more or less than +1 level.
- A Page Event reward fails to include at least one new gear card when legal unowned gear exists and a slot is open.
- A fixed weapon-only level overrides the normal draft roll.
- A pity rule forces a card outside the normal/event guarantee rules.

## Edge Cases

- If XP gain crosses multiple levels, queue drafts one at a time.
- If player dies during draft, death/victory flow decides whether the draft is canceled or resolved first.
- If the tiny prototype pool cannot produce 3 distinct legal cards, repeat a legal simple upgrade only after all distinct legal cards are already shown.
- If all normal weapon/item choices are exhausted, show overflow global `+5%` stat crumbs.
- If draft UI cannot open, store pending draft and log blocking error.
- If XP pickup pool is exhausted, pickup may merge values into nearby Color Motes.

## Dependencies

- **Resource Data Schemas**: Required draft metadata.
- **Weapons and Auto-Attacks**: Required weapon acquisition/leveling.
- **Passive Items and Drafts**: Required item acquisition/leveling.

## Tuning Knobs

| Knob | Default | Range | Notes |
|---|---:|---:|---|
| `draft_choice_count` | `3` | fixed | Current draft rule. |
| `normal_upgrade_weight` | `0.90` | tuning | Per-card upgrade chance. |
| `normal_new_gear_weight` | `0.10` | tuning | Per-card new gear chance. |
| `new_gear_weapon_weight` | `0.50` | tuning | Weapon side of legal new gear. |
| `new_gear_item_weight` | `0.50` | tuning | Item side of legal new gear. |
| `upgrade_weapon_weight` | `0.50` | tuning | Weapon side of legal upgrades. |
| `upgrade_item_weight` | `0.50` | tuning | Item side of legal upgrades. |
| `max_weapon_slots` | `5` | fixed for MVP | Shared with weapon system. |
| `max_passive_slots` | `5` | fixed for MVP | Shared with item system. |
| `overflow_stat_bonus` | `5%` | tuning | Repeatable crumb only when no normal legal cards exist. |
| `xp_curve_base` | `10` | `1+` | Prototype tuning. |
| `xp_curve_growth` | `1.12` | `1.0-1.5` | Prototype tuning. |

## Visual/Audio Requirements

- Color Motes must be visible on paper and readable under VFX.
- Level-up draft should feel rewarding with clear card feedback.
- XP pickup and draft selection SFX should be short and satisfying.

## UI Requirements

- Draft modal shows exactly 3 choices with icon, title, category, level, description, rarity/style treatment, and compatibility hints where relevant.
- HUD shows XP bar, run level, weapon slots, item slots, and pending draft state.
- Gamepad/keyboard navigation must work without hover.

## Acceptance Criteria

- Color Mote XP can fill a run-level bar.
- Level-up opens exactly 3 choices.
- Normal cards use `90%` upgrade and `10%` new gear rolls before legality redirects.
- Gear rolls split `50%` weapon and `50%` item before legality redirects.
- Upgrade rolls split `50%` weapon and `50%` item before legality redirects.
- Draft eligibility respects 5 weapon slots, 5 item slots, weapon level 10, and item level 5.
- New gear enters at level 1.
- Owned weapon and item upgrade choices grant fixed +1 level.
- Page Event reward includes at least one new gear card when legal unowned gear exists and a slot is open.
- No fixed weapon-only level, pity, elite chest, or boss reward draft is required for the first polished exemplar.
- Overflow appears only when no normal legal card exists.

## Open Questions

- Exact XP curve values are prototype-tuned.
- Full-content duplicate-card policy can be tightened once the real weapon/item pool is active.
