# First 5-Minute Slice Facts (updated 2026-05-14)

- Branch `feat/mvp` implements the first polished exemplar package as a thin playable spine. Locked package: Waxlight Comet starter weapon, Candle Spark passive, Dog support pet, Color Well Page Event, Wax Imp/Flicker Imp enemy family, Crownless Echo finale tease.
- Content implementation guardrail: initial/correction work for weapons, passive items, enemies, Page Events, chapters, Pagecraft materials, pets, characters, bosses, or unlocks must consult `PAGEBOUND_CODEX_GDD_v1_5.md` plus focused `design/gdd/*` docs and record `Design source consulted: ...` in bead/session-state.
- Run still boots to start menu; timer, director, weapons, pickups, and player control stay idle until Start Run/accept. Death screen exposes Retry/Main Menu and retry resets run state.
- Draft/loadout spine: 3-card drafts, 5 weapon slots + 5 item slots. Normal drafts roll through `DraftChoicePicker`: 90% upgrade / 10% new gear, with 50/50 weapon/item category attempts and legality redirect. Current first-package legal normal cards are Waxlight Comet +1 and Candle Spark/new-or-upgrade, filling duplicates only when tiny-pool exhaustion requires 3 cards. Page Event reward drafts guarantee a new gear card when legal. No pity, fixed weapon-pick levels, elite/chest rewards, boss reward draft, Pagecraft modifiers, or event evolutions in this package.
- First-polished HUD uses structured player-facing controls instead of debug text: top-left party reserve, top-right exclusive Page Event/boss banner, larger HP chip, bottom full-width XP percent bar, Level badge, Dog pet badge/feedback, and visible 5 weapon + 5 item loadout slots. It intentionally omits director/debug stat text.
- Dog support pet spawns as a visible non-colliding follower. It is support-only, does no damage, and has pickup-assist aura around the player: T1 Color Motes, T2 health pickups, T3 larger radius. Pickup assist credits instantly and shows world/HUD feedback.
- Enemy content now uses `wax_imp` as the opening slow/sturdy family and `flicker_imp` as the delayed fast/weak pressure family. Opening Wax Imp HP equals two starting Waxlight hits. Director bands: `opening`, `first_pressure`, `flicker_surge`, `page_crush`; safety cap remains runaway protection, not pacing cap.
- Page/map is widened for offscreen objectives: runtime half-extents are 32 x 20, page mesh is 64 x 40, camera follow half-extents are 28 x 16. Old tests that assumed the whole page stayed in camera view are stale; camera should keep player/current play readable.
- Color Well Page Event starts at 1:00, spawns at a random reachable position outside current vision, exposes edge-marker state, lasts 60s, and requires 15 enemy deaths by death position inside the circle. Success opens a Page Event reward draft; failure gives no reward and run continues. Event and boss banners are exclusive.
- Crownless Echo (`crownless_echo`) is a killable mini-boss/finale tease scheduled around 3:30. If Color Well is active it queues until event resolution, then uses the top-right boss banner. Defeat drops XP/Color Motes only and does not open an in-run draft. The run no longer hard-stops at 5:00.
- Legacy Star Sticker/Dreamsap/Color Bloom code and direct smoke coverage still exist for older prototype systems, but they are not in the first polished weapon pool or normal/package draft surface. `PrototypeContentFactory.weapon_pool()` now returns only Waxlight Comet for the locked package; `weapon_for_id()` still supports legacy direct tests.
- No current attack artifact is indefinite: active Waxlight marks decay, inactive Waxlight marks expire plus cap enforcement, Waxlight dash pulses clean up, and Star Sticker page stickers pop/clean up in legacy tests.
