# First 5-Minute Slice Facts (updated 2026-05-15)

- Branch `feat/mvp` implements the first polished exemplar package plus the user-approved second content batch. Starter state is now `star_sticker_swarm` level 1 and Dog active, with no passive owned by default. `waxlight_comet` is a second weapon / early AoE Pagecraft weapon, not the starter baseline.
- Current playable weapon pool order is `star_sticker_swarm`, then `waxlight_comet`. `Star Sticker Swarm` is the starter baseline: base damage `100`, cooldown `0.9s`, target range `8.0m`, L1 has no Star nodes and no ricochet. At L5, normal Star hits create persistent Star nodes, base node cap is `5` plus `active_cap` upgrades, and node ricochets hit one enemy for `50%` damage. Star dash payoff unlocks at L5: dash fires a cooldown-free normal-target volley using current max orbit star count and does not create nodes. At L10, every node used for a ricochet fires one extra non-node Star for `50%` damage.
- `Waxlight Comet` is an early AoE/Pagecraft mark weapon: base damage `45`, cooldown `0.95s`, target range `6.5m`. L1-L4 show a short attack visual but leave no persistent Waxlight mark. Impact AoE applies full current weapon damage to every enemy inside the AoE, including secondary targets. Its marks and dash payoff unlock at L5; crossing an unactivated Waxlight mark triggers an instant one-time burst. At L10, crossing one currently unactivated mark activates the connected group of touching/overlapping currently unactivated Waxlight marks. Waxlight range upgrades scale both target range and any unlocked L10 connected-mark reach; size upgrades scale mark radius.
- Evolutions are intentionally skipped for current scope; weapon L5/L10 mechanics are implemented, but evolution designs remain deferred placeholders in docs.
- Current passive pool is `candle_spark`, `cloud_seed`, `dream_thread`, `ribbon_spool`, and `moon_button`. All are Common with +10/+20/+30/+40/+50% level ladders. Candle Spark is Firelight/Light damage; Cloud Seed is Bloom/Wonder size; Dream Thread is Dream/Thread duration; Ribbon Spool is Thread/Star range; Moon Button is Moon/Echo cadence with the level-5 low-HP cadence bonus modeled in runtime state.

- Run XP uses the user-approved continuous Vampire Survivors-style curve scaled by 5, without level 20/40 walls. Base enemy XP is 5; level 1 -> 2 costs 25 XP; total XP to level 50 is 67,225.
- Spawn pressure uses VS-inspired waves with an opening readability grace: min alive starts at 8, ramps to 25 by 1:00, then follows 25 -> 320 over the uncondensed 30-minute curve. Base spawn interval remains 1.0s -> 0.2s, target kill rate remains 1 -> 10 kills/sec, pressure spawns are suppressed above-minimum during the first minute, and max alive cap remains 350.
- Combat scale now matches the 1000 HP player baseline and Star starter: Wax Imp base HP `70`, Flicker Imp base HP `45`, normal contact damage `60`, Crownless Echo HP `2400`, boss contact damage `160`, boss XP reward `1000`. Enemy HP multiplier is eased `1x -> 8x` over 30 minutes with `1 + 7 * pow(t, 1.6)`.
- Draft/loadout spine: 3-card drafts, 5 weapon slots + 5 item slots. Normal drafts roll through `DraftChoicePicker`: 90% upgrade / 10% new gear, with 50/50 weapon/item category attempts and legality redirect. Page Event reward drafts guarantee a new gear card when legal. Draft cards include category, rarity, icon text, title, stat delta, description, level transition, and deduplicated tags; slot/evolution hint lines are intentionally omitted. Multiple level-up drafts queue one at a time.
- HUD is player-facing: top-middle run timer, hidden solo top-left party placeholders, top-right exclusive Page Event/boss banner, larger HP chip, dash recharge meter, bottom full-width XP percent bar, Level badge, Dog icon/feedback, and visible 5 weapon + 5 item loadout slots with levels. Escape/debug pause menu shows run stats, weapon/item levels, each weapon's applied upgrades, and Resume/Options/Quit controls.
- Dog support pet spawns as a visible non-colliding follower. Latest user clarification overrides stale aura docs: Dog has no pickup aura and does not instantly credit pickups at range. It extends player pickup reach by detecting eligible pickups in fetch range, paths to them with simple AI, then credits the pickup only when reached. Once Dog starts moving toward an eligible pickup, leaving fetch range does not cancel that fetch; only the pickup becoming non-collectible ends it early. T1 fetch range is 6.0m, exactly 100% larger than the player's 3.0m XP pickup radius; T2 also accepts health pickups; T3 fetch range is 8.625m. Developer-only XP range debug circles can be toggled to show the player's pickup radius and Dog fetch radius.
- Current first-playable range/cadence pass makes weapon target ranges smaller and slows level-1 attacks before increasing spawn pressure: Star `8.0m` / `0.9s`, Waxlight `6.5m` / `0.95s`. Spawn curves remain unchanged until playtest.

Success opens a Page Event reward draft; failure gives no reward and run continues. Event and boss banners are exclusive.
